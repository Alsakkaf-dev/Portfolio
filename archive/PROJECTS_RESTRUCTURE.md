## 🎯 How to Add New Projects

### **Quick Steps:**

1. **Create your project folder** in `Projects/`
   ```
   Projects/
   └── Your-New-Project/
   ```

2. **Add your project files**
   ```
   Your-New-Project/
   ├── README.md
   ├── index.html
   └── src/
   ```

3. **Update the main README**
   - Add your project to `MOHAMMED-ALSAKKAF/README.md`

4. **Update Projects README**
   - Add entry to `Projects/README.md`
