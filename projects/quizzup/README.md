## 🌟 Overview

**QuizzUp** is a modern, interactive quiz platform that combines gamification with education. Built with a focus on user experience and performance, it provides students with an engaging way to test their knowledge while competing on a global leaderboard.

### The Story

QuizzUp was born from a need to create an engaging, competitive learning environment for students. The challenge was to build a system that not only tests knowledge but also motivates continuous learning through gamification, leaderboards, and real-time feedback.

## ✨ Features

### Core Functionality
- ✅ **Dynamic Quiz Generation** - Multiple question types (MCQ, True/False)
- ✅ **Real-time Leaderboard** - Competitive ranking system with point tracking
- ✅ **User Authentication** - Secure login and profile management
- ✅ **Progress Tracking** - Monitor learning progress and performance

### Admin Features
- ✅ **Admin Panel** - Complete content and user management
- ✅ **Advanced Search** - Real-time filtering with text highlighting
- ✅ **User Management** - View, search, and manage all users
- ✅ **Question Bank Management** - Add, edit, and organize quiz questions

### UI/UX
- ✅ **Premium Design** - Modern glassmorphism aesthetic
- ✅ **Smooth Animations** - Engaging micro-interactions
- ✅ **Responsive Layout** - Works seamlessly on all devices
- ✅ **Dark Mode Support** - Eye-friendly interface

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required (runs locally)

### Installation

1. **Clone or download** the project
2. **Open** `index.html` in your browser
3. **Start learning!**

### First Time Setup

1. **Create an account** on the sign-up page
2. **Choose a chapter** to start quizzing
3. **Compete** on the leaderboard
4. **Track your progress** in the dashboard

### Admin Access

To access admin features, use the admin credentials (configured in the application).
